# NEON HANGMAN GAME 🎮

A modern Hangman Game developed using Python and Tkinter.

## Features
- Dark Neon Gaming Theme
- 6 Word Categories
- Easy, Medium and Hard Levels
- 60+ Words
- Hint System
- Score Tracking
- Sound Effects
- Maximum 6 Wrong Attempts
- Multiple Rounds

## Technology Used
- Python
- Tkinter
- Random Module
- Threading
- Winsound

## How to Run
1. Install Python.
2. Open the project folder.
3. Run this command:

   python main.py
