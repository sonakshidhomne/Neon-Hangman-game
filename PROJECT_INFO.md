# 🎮 Neon Hangman Game

A modern and interactive Hangman Game developed using Python with a dark neon gaming theme.

## ✨ Features
- Attractive Dark Neon Gaming UI
- Multiple Word Categories
- Multiple Game Rounds
- Sound Effects
- Score Tracking
- Interactive Gameplay
- Random Word Selection

## 🛠️ Technologies Used
- Python
- Tkinter
- Pygame (if used for sound)

## ▶️ How to Run

1. Clone this repository.
2. Install required dependencies.
3. Run the following command:

```bash
python main.py
```

## 🎯 Project Objective

To develop an engaging GUI-based Hangman Game that improves vocabulary and provides an enjoyable gaming experience.
